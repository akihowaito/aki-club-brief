# 定制化俱乐部网页 · 建站需求收集工具

白色为主、彩虹渐变标识与淡彩色分区的俱乐部建站需求工作台。六步整理基础资料、品牌方向、菜单内容、功能、客服部署及参考素材。

支持游戏与关键词表情标签、24 种品牌风格和其他补充、多个主色与辅助色色卡、时间段或 24 小时客服、三种部署选项、参考图片导入、自动保存与恢复、需求预览与复制、TXT / PNG / PDF 导出、JSON 草稿备份与恢复。保留旧版 `aki_club_brief_*_v1` 草稿兼容；旧部署选项会映射到新的三种选择。

线上地址：https://akihowaito.github.io/aki-club-brief/

## 本地运行

无运行时依赖，无构建步骤：

```sh
python -m http.server 4178
```

打开 `http://localhost:4178/`。也可直接打开 `index.html`，但建议 HTTP / HTTPS 访问，以保持可靠的浏览器存储与复制行为。

## 数据与分享

数据与参考图片仅保存在当前浏览器的 localStorage，网站不会自动提交或发送给任何人。清除浏览器数据、换设备或换域名都可能失去本机草稿；请使用「导出草稿」保存 JSON 备份，再在目标浏览器导入。导出的文件可能包含客服账号等资料，请自行保管。

PNG 采用清单本子排版，宽 1080 px，按实际内容自动计算高度，附带色卡、其他补充和参考图片。超过 18000 px 时明确提示缩短内容或改用文字导出，不裁切内容。PDF 为真正的 A4 多页文件，按安全位置分页，保留同样的排版与图片。

生成图片与 PDF 后，支持文件分享的浏览器可直接打开系统分享菜单。微信内不支持系统文件分享时，可长按真实清单图片保存或发送给 akihowaito；PDF 可打开预览和保存，若微信拦截下载，可在浏览器中打开网站后保存发送。网站不会自动选择收件人。

参考图片最多 6 张，每张原图最多 10 MB，导入时会缩至最长边 1200 px 并保存为 JPEG（GIF 使用静态首帧）。压缩后的图片合计不超过 1.8 MB；JSON 备份限 3 MB，含实际参考图片。导入备份会在确认后覆盖当前项目。模板设置入口已移除。

## 验证

安装 Playwright 及 Chromium 后，在运行本地 HTTP 服务时执行：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser-check.cjs
```

可通过 `TEST_URL` 指定测试网站，`ARTIFACT_DIR` 指定测试下载与截图目录。测试使用独立浏览器环境，不修改真实用户草稿。

## GitHub Pages

发布整个目录到仓库 `main` 分支，在仓库 Settings → Pages 选择 Deploy from a branch → `main` → `/ (root)`。所有资源使用相对路径，可部署到 GitHub Pages 项目子路径，无外部 CDN 或字体依赖。

功能选项用于记录建站需求。勾选后台、付款或数据统计不表示这个需求工具提供对应业务系统。
